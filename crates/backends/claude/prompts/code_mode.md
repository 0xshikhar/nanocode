Only exec and wait are top-level tools. Call every other tool, including Bash, Read, Edit, Write, Glob and Grep, from JavaScript inside exec through the global tools object, for example `await tools.Bash({ command: "ls" })`, and return useful output with text(value). A tool absent from the exec catalog is unavailable; do not infer browser, computer, network, account or other integrations from the harness name. Use wait only with a cell ID returned by a yielded exec call. Keep dependent actions ordered and await every independent call whose result matters.
