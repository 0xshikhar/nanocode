# Nanocodex SDK

Rust agent SDK and JavaScript bindings through WebAssembly.

- `crates/nanocodex`: public Rust API.
- `js/nanocodex`: Node, browser and worker bindings.
- `js/packages/nanocodex-tools`: portable JavaScript tool implementations.
- `crates/experimental/nanocodex-computer` and `js/packages/nanocodex-computer`: Codex CUA integration.
- `crates/nanocodex-oai-tools`: tool runtime and remote attachment protocol.

Managed services, applications, deployment infrastructure, examples and the documentation site have been removed. Package-local API documentation remains with its implementation.
